第 2 周九题分享 · 混合层、温盐结构与热收支

我学到了什么

  • 老师课件上的九个问题，主线是混合层和温盐结构。混合层深度不是固定值：风混合典型 20–100 m，副极地冬季可达 80–120 m；靠冷却驱动的深层对流能到几百米。
  • 副热带北太平洋是三层结构：混合层（20–40 m，25–29 ℃）→ 主温跃层（100–800 m）→ 深层冷水；盐度在 150–200 m 出现次表层最大值 34.8–35.2。
  • 表层盐度由蒸发减降水（E−P）控制：副热带 E>P 形成盐度极大值，ITCZ 一带 P>E 形成低盐带。
  • 位温（Potential temperature）：去掉绝热压缩影响后的温度，不同深度的水才能比较冷暖；位密同理，必须注明参考压力。
  • 混合层热收支四部分：表面热通量（净短波 − 长波 + 感热 + 潜热）、平流、卷入 / 卷出、储存项。

问题来自老师课程 PPT 的九个问题，答案整理见 九题分享。

第 3 周EOF 主成分分析

我学到了什么

  • 海温场里每个格点都在变，EOF 把变化拆成「空间型 × 时间系数」两部分。
  • 第一模态对应厄尔尼诺型的空间分布，时间系数反映它什么时候强、什么时候弱；各模态互不相关，按方差贡献排序。
  • 用 3B1B 的方式做了 18 秒小动画：先讲清「为什么能这样拆」，再讲「怎么算」。
  • 顺手把网站部署到了 GitHub，拿到了对外可访问的链接。

相关内容：EOF 主成分分析　·　EOF 是怎么算出来的（18 秒）

当时没懂 → 后来想通

当时没懂EOF 出来一堆「空间型」和「时间系数」，空间型还能看图，时间系数就只有一条上下起伏的曲线——它到底在说什么？是温度吗？正负又代表什么？

后来想通时间系数不是另一个物理量，而是「这一刻，这个空间型在场里占多大份量」。把某时刻的场减去平均态，再投影到第一模态的空间型上，就得到那一刻的系数：正号说明此刻的海温分布接近第一模态的正相位（厄尔尼诺型），负号就是反相（拉尼娜型），绝对值越大越像。它的单位和原始场一致（标准化之后无量纲），所以只有把「空间型 × 时间系数」乘回去，才能还原出原来那个场。

第 4 周从海水密度到地转流速

我学到了什么

  • 惯性流：风停之后，水质点在科氏力作用下继续做圆周运动；地转偏向力随纬度变化，决定往哪边偏。
  • 埃克曼深度：风应力的影响随深度迅速衰减的特征尺度。
  • 从密度到流速是四步：密度剖面 → 等密度线倾斜 → 比容异常与动力高度（要积分）→ 海面坡度与压力梯度 → 地转流速。
  • 图 7.11 就是这套流程的一次实测：位密度剖面 → 比容偏差 → 动力高度 → 东向地转速度。

相关内容：从海水密度到地转流速（含互动小测）

当时没懂 → 后来想通

当时没懂动力高度为什么一定要积分？某一层的密度异常，不能直接说明海面高低吗？

后来想通海面高度是所有层比容异常累加的结果——上层贡献大、深层贡献小，但都要算进去。只看某一层，等于只看了这个累加和里的一项：层的厚度不一样，同样大小的比容异常对海面高度的贡献本来就不一样，所以必须一层一层积起来，才谈得上「海面被抬高了多少」。

第 5 周Sverdrup 平衡、埃克曼抽吸与位涡守恒

我学到了什么

  • 核心是位涡守恒：水柱被拉伸就往极地方向移动，被压扁就往赤道方向移动。
  • 整条链子：风 → 表层水辐聚 / 辐散 → 水柱拉伸 / 压缩 → 为了守恒，底层水柱被迫向极地 / 赤道移动 → 形成广阔的内部斯维尔德鲁普流（Sverdrup flow）→ 最后由西边界流（强流）闭合环流。
  • 埃克曼抽吸（Ekman pumping）：把风应力的旋度变成垂向运动的那个环节。

当时没懂 → 后来想通

当时没懂Sverdrup Balance 到底在说什么？为什么风能让整个海盆的水往一个方向输运？

后来想通关键在位涡守恒：由于位涡守恒，海水柱被拉伸，就往极地方向移动；海水柱被压扁，就往赤道方向移动。把这一条约束和风应力造成的表层辐聚 / 辐散接上，才推得出内部一致的那支斯维尔德鲁普输送——它不是「风把水吹过去」，而是水柱为了守住位涡被迫南北移动。

当时没懂 → 后来想通

当时没懂位涡守恒有的地方写成 f + ζ = 常数，有的地方又写成 (f + ζ)/H = 常数，到底要不要除以水深？

后来想通两条只在 H 不变时等价：水柱厚度一定，两边同乘 H 就把分母约掉了，剩下绝对涡度守恒。但 Sverdrup 平衡里 H 恰恰在变——埃克曼抽吸让水柱拉伸或压扁，所以必须写 (f + ζ)/H；要是按 f + ζ 守恒，拉伸压缩对流动毫无影响，斯维尔德鲁普输送根本推不出来。

第 6 周波的基本特征与相速

我学到了什么

  • 第一张图回答「什么是波」：扰动被拉回平衡位置却冲过了头，就形成波——所以必须有恢复力。
  • 波把扰动从一处传到另一处（长距离传播），但水体本身没有显著整体移动（质量输运很小）。
  • 波同时是能量的载体：能量随波传播——这也是它最「能干」的一项。
  • 第二张图讲相速怎么定：色散关系 ω² = gk·tanh(kh)，相速 C = √[(g/k)·tanh(kh)]。
  • 深水（h > λ/2）：tanh 趋近 1，C = √(g/k)，只跟波长有关、与水深无关。
  • 浅水（h < λ/20）：tanh ≈ kh，C = √(gh)，只跟水深有关。

第 7 周罗斯贝波与波的类型

我学到了什么

  • 大洋罗斯贝波：核心恢复力是地球自转的 β 效应，传播方向向西。
  • 地形罗斯贝波：靠地形起伏带来的水深变化提供恢复力。

开头 · 现象与疑问

开头展示的是这一海域的海表温度锋面：左边冷水、右边暖水，中间那条颜色骤变的边界就是锋面，以及锋面附近的空间结构。海洋学家把锋面上那些又细又长的水带叫作 filaments，丝状结构——往往只有几公里到几十公里宽，却能伸出去几百公里；它们是怎么被拉出来的，后面用动画解释。

中间 · 我怎么找答案
  • 先找一张看得见锋面的图：取 NASA MUR SST（1 km 分辨率）湾流区某一天的海表温度，蓝色是冷水、红色是暖水，中间那条颜色骤变的边界就是锋面。
  • 再自己算梯度：把每个格点与相邻格点相减、取模，得到水平温度梯度场——也就是「温度变化最快的地方」。
  • 把梯度最大的一小部分像素标成白色，叠回原图：高梯度带一条一条，正好压在肉眼看到的丝上。
  • 最后想机制：流场里同时有拉伸和挤压，一小团水落进去就会被越拉越长、越拉越细，所以丝总是顺着锋面走。
结尾 · 结论与还想知道的

细丝不只是物理现象。它像一条传送带：把深层富营养的水送进透光层，浮游植物会沿着这条带生长，鱼群和幼体也常常跟着丝走。

如果这些丝几天内就散掉，靠它吃饭的生物该怎么办？这正是生物海洋学正在研究的问题。
