这是一个**纯静态**的知识分享站点，托管在 GitHub Pages 上，自带 `https://` 链接，打开就能看，链接发出去就能分享。

## 它有什么特点

- **零构建**：没有打包步骤，改完内容保存即生效，不用担心构建失败。
- **在线编辑**：点右上角「写笔记」，在网页里直接写 Markdown，保存后提交到 GitHub 仓库。
- **秒级更新**：配置了访问令牌后，你自己刷新页面立刻能看到最新内容（走 GitHub API，绕过 CDN 缓存）。
- **可分享**：每篇笔记都有独立链接，点「复制链接」就能发给别人。

## 怎么开始写第一篇

1. 点右上角的 **设置**，填入你的仓库信息和 GitHub 访问令牌。
2. 点 **写笔记**，填标题、写正文。
3. 点 **保存**，几秒后刷新即可看到。

> 令牌只保存在你自己浏览器的 localStorage 里，不会提交到仓库，也不会发给任何第三方。

## 支持的写法

标题、列表、表格、代码块、引用、任务清单都支持，具体可以看 [Markdown 速查](#/n/markdown-guide)。

```js
// 支持代码块
function hello(name) {
  return `你好，${name}！`;
}
```
