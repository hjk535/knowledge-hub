## 文本

| 写法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `` `代码` `` | `代码` |

## 标题

```text
# 一级
## 二级
### 三级
```

## 列表

```text
- 无序
1. 有序
- [ ] 待办
- [x] 已完成
```

## 引用

```text
> 引用内容
```

## 链接与图片

```text
[文字](https://example.com)
![说明](图片路径)
```

## 代码块

用三个反引号包起来，开头写上语言名可以着色：

```python
def add(a, b):
    return a + b
```

## 表格

```text
| 列一 | 列二 |
| --- | --- |
| 内容 | 内容 |
```

## 分隔线

```text
---
```
