# Markdown 速查

## 文本

| 写法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `` `行内代码` `` | `行内代码` |

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 列表

```markdown
- 无序项
- 无序项

1. 有序项
2. 有序项

- [ ] 待办
- [x] 已完成
```

## 引用与分隔线

```markdown
> 这是一段引用

---
```

> 这是一段引用

---

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](图片地址)
```

## 代码块

用三个反引号包起来，并在开头写上语言名可以启用语法着色：

````markdown
```python
def add(a, b):
    return a + b
```
````

```python
def add(a, b):
    return a + b
```

## 表格

```markdown
| 列一 | 列二 |
| --- | --- |
| 内容 | 内容 |
```

## 提示

正文里可以用 `> **注意**：...` 这样的写法突出重点，例如：

> **注意**：标题和标签写在文件开头的 `---` 之间（front matter），不要在正文里重复写标题。
